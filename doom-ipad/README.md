# Doom Player für iPad (PWA)

Webapp auf Basis von js-dos (DOSBox als WebAssembly, GPL-2.0). Enthält **kein** Doom-Material.

## Starten
1. Ordner auf einen HTTPS-Host legen (z. B. GitHub Pages). Service Worker und "Zum Home-Bildschirm" brauchen HTTPS.
2. Auf dem iPad in Safari öffnen -> Teilen -> "Zum Home-Bildschirm".
3. In der App ein ZIP mit `DOOM.EXE` + `DOOM.WAD` wählen. Die frei verteilbare Shareware-Version von id Software ist dafür geeignet.
   Die Vollversion nur mit deiner eigenen, legal erworbenen Kopie.

## Steuerung
js-dos blendet auf dem iPad eine Bildschirmtastatur und Touch-Steuerung ein. Externe Tastatur funktioniert ebenfalls.
